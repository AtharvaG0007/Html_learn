# My Expense Tracker

A beginner-friendly expense tracker made with HTML5, CSS3 and plain JavaScript.

## Project files
- `index.html` - page structure and form
- `style.css` - colours, layout and mobile design
- `script.js` - calculations, adding, deleting, filtering and saving data

## Features
- Add income and expense entries
- Select a category and date
- Automatically calculate income, expenses and balance
- Filter transactions by type
- Delete one transaction or clear all
- Save entries in browser Local Storage
- Responsive layout for mobile and desktop

## How to run
Download or clone this repository and open `index.html` in a browser. No npm, Node.js, server or database is required.

## Simple explanation for viva
- HTML creates the structure of the website.
- CSS controls its design and layout.
- JavaScript makes the website interactive.
- An array stores the transactions.
- Each transaction is an object containing description, amount, type, category and date.
- Functions organize repeated tasks.
- Event listeners run code when the user submits the form or clicks a button.
- Local Storage saves the data in the current browser.

**Balance = Total Income - Total Expenses**

## Limitation
Data is saved only in the same browser on the same device. This beginner project does not have user accounts, a server or cloud synchronization.
